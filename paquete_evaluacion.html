Lenguaje de programación orientada a objetos con Java#u1

Conocerás las características de Java y su entorno de desarrollo, definiendo clases, atributos y métodos para implementar objetos en programas.

Conceptos clave

Clase
Molde o plantilla que define atributos y métodos; a partir de ella se crean objetos.
Objeto
Entidad concreta con características (atributos) y comportamiento (métodos).
Identidad
Propiedad que distingue a un objeto de los demás, aunque tengan los mismos valores.
Atributo
Propiedad guardada en una variable; su valor puede variar entre objetos.
Método
Acción que el objeto puede realizar, descrita por instrucciones.
Abstracción
Quedarse con las características y acciones esenciales de una entidad y ocultar detalles.
Instancia
Objeto creado a partir de una clase con new; cada instancia tiene sus propios valores.
JVM
El compilador genera bytecode (.class); la Máquina Virtual de Java lo ejecuta en cualquier sistema.

public class Persona {

    private String nombre;

    // Constructor
    public Persona(String nombre, int edad) {

    Clase y atributo

    Una clase describe qué datos guardará un objeto y qué podrá hacer. Se declara con class y un sustantivo con mayúscula inicial. Los atributos son variables declaradas dentro de la clase y fuera de cualquier método; también se llaman campos o variables de instancia.

    Carro.javaEjemplo 2: declaración de atributos

public class Carro {
    // Atributos
    String marca;
    String modelo;
    String color;

    // Método para mostrar detalles del carro
    public void mostrarDetalles() {
        System.out.println("Marca: " + marca);
        System.out.println("Modelo: " + modelo);

    Métodos, getters, setters e instanciación

    Un método es un bloque de instrucciones con nombre que realiza una tarea. Si devuelve un valor usa return; si no, su tipo es void. Los métodos de instancia requieren un objeto; los métodos de clase llevan static y se invocan sin crear objetos, como main.

    • Getter: public String getNombre(), devuelve el valor del atributo privado.
    • Setter: public void setNombre(String nombre), recibe el nuevo valor; usa this.nombre para referirse al atributo.
    • Instanciar: Persona p = new Persona();, donde new invoca al constructor.

    Tipos de errores

    Sintácticos: el compilador los detecta (paréntesis sin cerrar, falta de ;, nombre inválido). Lógicos: el programa compila y corre, pero el resultado es incorrecto. Prueba el de la derecha.

    Math.sqrt de un negativo da NaN (Not a Number). El programa no falla, pero el resultado no tiene sentido: es un error lógico. Se corrige validando con if (numero >= 0).

    import java.util.Scanner;

public class MayorDeTresNumeros {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        // Solicitar los tres números al usuario
        System.out.print("Ingrese el primer número: ");
        int num1 = teclado.nextInt();
        System.out.print("Ingrese el segundo número: ");
        int num2 = teclado.nextInt();
        System.out.print("Ingrese el tercer número: ");
        int num3 = teclado.nextInt();

        // Determinar el número mayor
        int mayor;
        if (num1 >= num2 && num1 >= num3) {
            mayor = num1;
        } else if (num2 >= num1 && num2 >= num3) {
            mayor = num2;
        } else {
            mayor = num3;
        }
        // Mostrar el resultado
        System.out.println("El número mayor es: " + mayor);
        teclado.close();
    }
}

    2.2

    Condicional múltiple: switch

    switch compara el selector con cada case. Al coincidir, ejecuta desde ahí hasta encontrar break; si no coincide ninguno, ejecuta default. El selector puede ser char, byte, short, int, sus clases envoltorio, String o un enum.

    8
    Versión de Java: la etiqueta con varios valores case 9, 10: que usa el ejemplo original requiere Java 14 o posterior. En versiones anteriores se escribe case 9: case 10:.
    Calculadora.javaAutoevaluación 2.2 resuelta
    import java.util.Scanner;
public class Calculadora {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int opcion;
        do {
            System.out.println("\n--- CALCULADORA ---");
            System.out.println("1. Suma");
            System.out.println("2. Resta");
            System.out.println("3. Multiplicación");
            System.out.println("4. División");
            System.out.println("5. Salir");
            System.out.print("Elige una opción: ");
            opcion = teclado.nextInt();
            if (opcion >= 1 && opcion <= 4) {
                System.out.print("Ingresa el primer número: ");
                double num1 = teclado.nextDouble();
                System.out.print("Ingresa el segundo número: ");
                double num2 = teclado.nextDouble();
                switch (opcion) {               // a) switch
                    case 1:
                        System.out.println("Resultado: " + (num1 + num2));
                        break;
                    case 2:                     // b) case
                        System.out.println("Resultado: " + (num1 - num2));
                        break;
                    case 3:
                        System.out.println("Resultado: " + (num1 * num2));
                        break;                  // c) break
                    case 4:                     // d) case
                        if (num2 != 0) {
                            System.out.println("Resultado: " + (num1 / num2));
                        } else {
                            System.out.println("Error: No se puede dividir entre 0.");
                        }
                        break;                  // e) break
                }
            } else if (opcion == 5) {
                System.out.println("Saliendo del programa...");
            } else {
                System.out.println("Opción no válida. Intenta de nuevo.");
            }
        } while (opcion != 5);
        teclado.close();
    }
}

    Arreglos unidimensionales

    Un arreglo es una secuencia de datos del mismo tipo bajo un solo nombre. Se declara con corchetes: int[] c; o int c[];. El primer índice es 0 y el último es length - 1.

    2.8–2.9

    Arreglos bidimensionales (matrices)

    Un arreglo bidimensional es un arreglo de arreglos: el primer índice es la fila y el segundo la columna. Con filas 0..m y columnas 0..n hay (m+1)·(n+1) elementos.

    int[][] tabla1 = { {51, 52, 53}, {54, 55, 56} }; // 2 × 3
double[][] matriz = new double[4][4];            // 4 × 4
tabla1[1][2]  // 56  → fila 1, columna 2
    2 3

    Los int ocupan 4 bytes; la posición relativa supone filas contiguas, como en la Tabla 1 de la guía (en la JVM cada fila es un objeto propio).

    ArregloBi.javaEjemplo 9
    import java.util.Scanner;
public class ArregloBi {
    static void leer(int a[][]) {
        int i, j;
        Scanner entrada = new Scanner(System.in);
        System.out.println("Entrada de datos de la matriz");
        for (i = 0; i < a.length; i++) {
            System.out.println("Fila: " + i);
            for (j = 0; j < a[i].length; j++)
                a[i][j] = entrada.nextInt();
        }
    }
    static void visualizar(int a[][]) {
        int i, j;
        System.out.println("\n\t Matriz leida\n");
        for (i = 0; i < a.length; i++) {
            for (j = 0; j < a[i].length; j++)
                System.out.print(a[i][j] + " ");
            System.out.println(" ");
        }
    }
    public static void main(String[] args) {
        int v[][] = new int[3][5];
        leer(v);
        visualizar(v);
    }
}

    Proyecto: GestionCalif

    Menú con do-while, opciones con switch, recorridos con for y un arreglo de 5 calificaciones. Úsalo como lo haría el programa en consola.

    GestionCalif.javaFigura 35
    import java.util.Scanner;
public class GestionCalif {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int opcion;
        double[] calificaciones = new double[5];
        int contador = 0;
        do {
            System.out.println("\nMenú de opciones:");
            System.out.println("1. Ingresar calificaciones");
            System.out.println("2. Mostrar calificaciones");
            System.out.println("3. Calcular promedio");
            System.out.println("4. Mostrar mayor y menor calificación");
            System.out.println("5. Salir");
            System.out.print("Seleccione una opción: ");
            opcion = teclado.nextInt();
            switch (opcion) {
                case 1:
                    if (contador < calificaciones.length) {
                        System.out.print("Ingrese la calificación: ");
                        calificaciones[contador] = teclado.nextDouble();
                        contador++;
                    } else {
                        System.out.println("No se pueden ingresar más calificaciones.");
                    }
                    break;
                case 2:
                    System.out.println("Calificaciones registradas:");
                    for (int i = 0; i < contador; i++) {
                        System.out.println("Calificación " + (i + 1) + ": " + calificaciones[i]);
                    }
                    break;
                case 3:
                    if (contador == 0) {
                        System.out.println("No hay calificaciones registradas.");
                    } else {
                        double suma = 0;
                        for (int i = 0; i < contador; i++) suma += calificaciones[i];
                        double promedio = suma / contador;
                        System.out.println("El promedio de las calificaciones es: " + promedio);
                    }
                    break;
                case 4:
                    if (contador == 0) {
                        System.out.println("No hay calificaciones registradas.");
                    } else {
                        double mayor = calificaciones[0];
                        double menor = calificaciones[0];
                        for (int i = 1; i < contador; i++) {
                            if (calificaciones[i] > mayor) mayor = calificaciones[i];
                            if (calificaciones[i] < menor) menor = calificaciones[i];
                        }
                        System.out.println("Mayor calificación: " + mayor);
                        System.out.println("Menor calificación: " + menor);
                    }
                    break;
                case 5:
                    System.out.println("Saliendo del programa...");
                    break;
                default:
                    System.out.println("Opción no válida, intente de nuevo.");
            }
        } while (opcion != 5);
        teclado.close();
    }
}

    Polimorfismo, constructores, colaboración y herencia de clases#u3

    Implementarás programas que aprovechan las bondades de la programación orientada a objetos.

    Constructor
    Método especial, con el mismo nombre de la clase y sin tipo de retorno, que inicializa los atributos al crear el objeto. Si no escribes uno, Java crea uno por defecto.
    Polimorfismo
    “Muchas formas”: un mismo método se comporta distinto según el objeto que lo ejecuta (sobrescritura con @Override).
    Sobrecarga
    Varios métodos o constructores con el mismo nombre y distintos parámetros en una misma clase.
    Herencia
    Una subclase (extends) recibe atributos y métodos de su superclase: relación es-un.
    Colaboración
    Clases que se comunican creando objetos, llamando métodos e intercambiando datos.
    super
    Referencia a la superclase; super(nombre) llama a su constructor y debe ser la primera instrucción.
    3.1

    Constructores y polimorfismo con @Override

    La variable es de tipo Mascota, pero el objeto real decide qué versión de hacerSonido() se ejecuta.

    Mascota m = new ("");

    Reglas de @Override: mismo nombre, mismos parámetros, modificador de acceso igual o menos restrictivo, y solo en herencia. Si el método no coincide, el compilador marca error, por eso la anotación es una buena práctica.

    Precisión conceptual: la guía llama “polimorfismo de constructores” a tener varios constructores con distintos parámetros. Técnicamente eso es sobrecarga. El polimorfismo en tiempo de ejecución ocurre con la sobrescritura de métodos, como en este laboratorio. En el examen, la respuesta esperada para “diferentes constructores con diferentes parámetros” sigue siendo esa opción.

    3.2–3.3

    Colaboración de clases

    Asociación

    Una clase usa los servicios de otra. El dueño usa a la veterinaria: llevarAVeterinaria(Veterinaria v).

    Agregación

    Una clase contiene objetos de otra que pueden existir por separado: Dueño tiene un atributo Mascota; una universidad tiene estudiantes.

    Composición

    Las partes no existen sin el todo: un automóvil tiene motor y ruedas que se crean con él.

    Mascota · Dueño · VeterinariaFiguras 14–17
    class Mascota {
    private String nombre, especie;
    private boolean enferma;
    public Mascota(String nombre, String especie) {
        this.nombre = nombre; this.especie = especie; this.enferma = false;
    }
    public String getNombre() { return nombre; }
    public boolean estaEnferma() { return enferma; }
    public void enfermar() { enferma = true; System.out.println(":( " + nombre + " se ha enfermado."); }
    public void curar() { enferma = false; System.out.println(":) " + nombre + " ha sido curado."); }
}

class Dueño {
    private String nombre;
    private Mascota mascota;                       // agregación
    public Dueño(String nombre, Mascota mascota) {
        this.nombre = nombre; this.mascota = mascota;
    }
    public void llevarAVeterinaria(Veterinaria veterinaria) {   // asociación
        System.out.println("\n ->" + nombre + " lleva a " + mascota.getNombre() + " a la veterinaria.");
        veterinaria.atenderMascota(mascota);
    }
    public void mascotaSeEnferma() { mascota.enfermar(); }
}

class Veterinaria {
    private String nombreVeterinaria;
    public Veterinaria(String nombreVeterinaria) { this.nombreVeterinaria = nombreVeterinaria; }
    public void atenderMascota(Mascota mascota) {
        if (mascota.estaEnferma()) {
            System.out.println("  Atendiendo a " + mascota.getNombre() + " en " + nombreVeterinaria + "...");
            mascota.curar();
        } else {
            System.out.println(":) " + mascota.getNombre() + " está sano y no necesita atención.");
        }
    }
}

public class GestionVeterinaria {
    public static void main(String[] args) {
        Veterinaria vet = new Veterinaria("Veterinaria Patitas Felices");
        Mascota mascota1 = new Mascota("Luna", "Perro");
        Mascota mascota2 = new Mascota("Michi", "Gato");

    Formulario2.javaAprendizaje 4.3
    import javax.swing.*;
import java.awt.event.*;
import java.awt.Color;

public class Formulario2 extends JFrame implements ActionListener {
    private JLabel label1;
    private JButton boton1, boton2, boton3;

    public Formulario2() {
        setLayout(null);
        label1 = new JLabel("Mensaje");
        label1.setBounds(140, 50, 100, 30);
        add(label1);
        boton1 = new JButton("VERDE");
        boton1.setBounds(30, 120, 80, 30);
        add(boton1);
        boton1.addActionListener(this);
        boton2 = new JButton("ROJO");
        boton2.setBounds(130, 120, 80, 30);
        add(boton2);
        boton2.addActionListener(this);
        boton3 = new JButton("AZUL");
        boton3.setBounds(230, 120, 80, 30);
        add(boton3);
        boton3.addActionListener(this);
    }

    public void actionPerformed(ActionEvent e) {
        if (e.getSource() == boton1) {
            label1.setText("VERDE");
            getContentPane().setBackground(Color.GREEN);
        } else if (e.getSource() == boton2) {
            label1.setText("ROJO");
            getContentPane().setBackground(Color.RED);
        } else if (e.getSource() == boton3) {
            label1.setText("AZUL");
            getContentPane().setBackground(Color.BLUE);
        }
    }

    public static void main(String args[]) {
        Formulario2 formulario1 = new Formulario2();
        formulario1.setTitle("Saludo");
        formulario1.setBounds(0, 0, 350, 250);
        formulario1.setResizable(false);
        formulario1.setLocationRelativeTo(null);
        formulario1.setVisible(true);
    }
}
